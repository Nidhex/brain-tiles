## 🌌 Overview

**Brain Tiles** transforms the classic 2048 formula into an electrifying neon-cyberpunk arcade experience. Built entirely without heavy frameworks or external media assets, it delivers a blazing-fast **60 FPS** tactile puzzle experience with procedural synthesized sound effects, fluid spring-physics transitions, persistent local memory, and full single-step undo.

```
       ┌───┐   ┌───┐   ┌───┐   ┌───┐
       │ 2 │ + │ 2 │ ─►│ 4 │   │ 8 │
       └───┘   └───┘   └───┘   └───┘
       ⚡ MERGE IDENTICAL NUMBERS TO REACH 2048 & BEYOND ⚡
```

| Feature | Description |
| :--- | :--- |
| 🎛️ **Deterministic 2048 Engine** | Strict mathematical fusion logic: exactly one merge per tile per turn, 90/10 probability generation for 2/4 tiles, and intelligent merge lookahead. |

## 🏗️ Architecture & Technical Feats

```
brain-tiles/
│
├── index.html        # Semantic HTML5, accessible ARIA roles & modal overlays
├── style.css         # Modern CSS custom properties, glassmorphism & 60fps animations
├── game.js           # 2048 board engine, audio synthesizer & state persistence
├── favicon.svg       # Geometric vector arcade logo
├── robots.txt        # Search engine discovery configuration
├── sitemap.xml       # SEO crawler index
└── README.md         # Documentation & deployment guide
```

### 1. Zero External Audio Files (Web Audio API)
Audio isn't loaded from external `.mp3` or `.ogg` files—it's synthesized on-the-fly using the browser's native **Web Audio API**:
- **Move Swoosh**: Frequency-swept band-pass oscillator for clean air-cushioned slides.
- **Merge Chimes**: Harmonically tuned sine wave dyads scaling in pitch as tile values increase.
- **Victory Anthem**: Multi-note ascending triad fanfare celebrating 2048 completion.

### 2. High-Performance CSS Transitions
Tiles utilize GPU-accelerated CSS `transform: translate3d(...)` with custom cubic-bezier timing curves for stutter-free 60 FPS movement on all hardware.

## ⚡ Quick Start (Run Locally)

No Node modules, build pipelines, or compilers required. Run with zero installation:

### Option 1: Instant Python Server
```bash
python -m http.server 8000
```
Then visit [`http://localhost:8000`](http://localhost:8000) in your browser.

### Option 2: Using Node `npx`
```bash
npx serve .
```

### Option 3: Direct Launch
Simply double-click [`index.html`](file:///d:/game1/game%202/index.html) in any modern web browser!
